## 🧠 Prompt Engineering

Prompt Engineering is the process of designing clear and effective instructions for an AI model to produce accurate, relevant, and predictable responses.

### Basic Prompt Structure

**Role + Task + Context + Constraints + Output Format**

### Key Concepts

* Clear Instructions
* Context
* Constraints
* Role
* Output Format
* Instruction Following
* Constraint Adherence
* Format Compliance

## 🎯 Key Learning

A good prompt should clearly communicate **what the model should do, the context it needs, the constraints it must follow, and the expected output format**.

This is especially important for **LLM evaluation**, where instruction following and constraint adherence are key evaluation criteria.
